# A day with Temoc

## Repository
https://github.com/nataliaaugsb/VisualNovel.git


## Description
A simple, interactive visual novel game where the player, who is a college student, has a conversation with Temoc about classes, school life, etc. 
The player's choices will affect how the conversation develops

The project relates to digital arts because it explores narrative design and user driven dialogue seen in popular video games such as Persona 3 Reload,
Ace Attorney, and other games.

## Features

- Interactive Dialogue
  - NPC generates dialogue on the screen and prompts the player to respond using 2-3 choices. 
- Branching conversation paths
  - Different player choices can lead to alternative dialogue outcomes using conditional logic.
-Simple visual assets using pygame
  - a character sprite with 2 different expressions displayed on the screen.
-Basic UI system
  -Buttons for player choices and a text box for dialogue
