Final Project for ANGM 2305.
A visual novel based game where Temoc gives the player a tour of 
UTD's campus. The player must choose which buildings they would
like to explore, which leads to two alternate endings.

I have two folders in my repository, one titled assets and another png_jpg. Png_jpg contain the original png/jpg files of backgrounds,
temoc sprites, and UI textboxes. The assets files also contains
backgrounds, temoc sprites, and UI textboxes but are labeled .bmp
so that they can load within pygame. Pygame was giving me some trouble for using png/jpg so I utilized .bmp files instead. I also have .mp3 files in assets. Essentially the game pulls the assets from the folder and implements it in the game when needed. 

I was really inspired by the game Persona 3 Reload when I made this project. The artstyle and UI of the game is phenomenal, so I wanted 
to make my own version of it. I utilized UTD's school colors, green primarily and orange as it's fitting with the theme of the game.

I think my game could be expanded upon if I had more time. More temoc sprites with different facial expressions would have helped
flesh the game out more. The backgrounds could be improved upon
as well. Perhaps instead of using images from UTD's website I could
have drawn them myself. Adding text animations, maybe eyeblink animations, etc could help make the game feel more alive. But for what it is, I think I am happy with what I made so far.
